1. PROJECT INITIALIZATION & SYSTEM ARCHITECTURE
================================================================================

Role & Purpose:
SpillTwin was engineered as an autonomous maritime surveillance and hazard
attribution digital twin. It provides continuous environmental protection across
congested waterways, narrow shipping fairways, and traffic separation schemes (TSS).

Core Stack:
- Frontend: React 18, TypeScript, Tailwind CSS, Leaflet GIS, D3.js (Bivariate KDE)
- Backend: Node.js, Express, TSX proxy routes
- AI & Multimodal Engine: @google/genai TypeScript SDK (Gemini 3.8 Flash)
- Audio: Web Audio API (VHF squelch tone synthesis), SpeechSynthesis API
